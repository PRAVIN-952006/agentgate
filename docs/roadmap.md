# Roadmap

## Next

- live stdio MCP discovery behind an explicit opt-in;
- VS Code and Cursor config fixtures;
- stable config schema documentation;
- baseline signing or external provenance;
- SARIF integration documentation;
- clean-environment macOS/Linux/Windows matrix.

## Not planned for MVP

- server certification;
- runtime sandboxing;
- network MCP authorization;
- secret decryption;
- AI-based tool-semantic analysis;
- managed SaaS control plane.

All additions require tests and a threat-model update.
